💡 How It Works

  • The script uses Python's os and shutil modules.
  • Both .jpg and .jpeg extensions (including uppercase) are detected.
  • Safe Duplication Handling: If a file with the same name already exists in the destination folder, AutoTask appends an incremental counter (e.g., image_1.jpg, image_2.jpg) without silently overwriting.
  • Subdirectories within the source folder are preserved and not altered.

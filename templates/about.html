About the Project

Academic Project: Task Automation with Python Scripts.

Project Objective

AutoTask is a robust, full-stack web-based automation platform designed to streamline repetitive daily computer tasks using Python scripts. It bridges the gap between backend command-line automation and beginner-friendly web interfaces, providing authenticated users with immediate execution, status tracking, and downloadable output files.

Core Automation Modules

1. JPG File Organizer: Uses Python's os and shutil modules to safely categorize and migrate image files into dedicated target folders while resolving filename duplicates non-destructively.
2. Email Address Extractor: Employs regular expressions (re) to extract, validate, and order unique email addresses from uploaded plain text documents, exporting the clean list into a downloadable file.
3. Webpage Title Scraper: Fetches remote public HTML using requests and BeautifulSoup4 to retrieve the page <title>, featuring industry-standard Server-Side Request Forgery (SSRF) defenses.

Technology Stack

💻 Frontend: HTML5, CSS3, Vanilla JavaScript (Fetch API, DOM manipulation)
🐍 Backend: Python, Django Web Framework (MVT Architecture)
🗄️ Database: MySQL Server managed via XAMPP, Django ORM
🛡️ Security: Django CSRF Protection, Password Hashing, SSRF Guard, Safe Workspace Isolation
🖥️ Environment: Windows 10/11, PyCharm Professional/Community, XAMPP

Key Security Principles

  • Safe Workspace Jail: File operations cannot traverse outside the administrator-approved workspace root directory.
  • SSRF Defense-in-Depth: Scraper rejects loopback, private RFC-1918 subnets, cloud metadata IPs, and re-validates DNS on every redirect.
  • Ownership Isolation: Regular users can only access and download records and files they generated.
  • Audit Logging: All execution starts, successes, failures, and file downloads are permanently recorded in the database.
